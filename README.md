# Hosterr Website

A modern and responsive hosting website landing page built with React and Tailwind CSS.

## 📌 About the Project

Hosterr is a responsive website landing page designed for a web hosting service.

The main section encourages users to host their website quickly and join a wishlist by entering their email address.

The project uses reusable React components and Tailwind CSS utility classes to create a clean and responsive user interface.

## ✨ Features

- Responsive landing page
- Modern and clean user interface
- Website hosting hero section
- Email address input
- "Join Wishlist" button
- No-spam message
- Responsive layout for different screen sizes
- Image integration
- Hover effect on the button

## 🛠️ Technologies Used

- React.js
- JavaScript
- Tailwind CSS
- HTML5
- Vite
- React Icons
- Git
- GitHub

## 📱 Responsive Design

The website is designed to adapt to different screen sizes using Tailwind CSS responsive classes.

It provides different layouts for:

- Mobile
- Tablet
- Desktop
